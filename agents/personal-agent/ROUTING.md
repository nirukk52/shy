- Family/personal WhatsApp messaging coordination
- Reminders/todos/calendar upkeep
- Household/personal routine automation
- Day-to-day logistics (weather, food orders, places)

- Multi-project software architecture
- Client growth/outreach strategy
- Cross-agent orchestration beyond personal domain
